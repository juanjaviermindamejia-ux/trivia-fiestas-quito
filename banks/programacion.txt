--------------------------------------------------------------------------------

1. [Nivel: Básico] ¿Cuántos valores diferentes puede representar un único byte compuesto por $8$ bits?
   A) $128$ valores distintos.
   B) $256$ valores distintos.
   C) $512$ valores distintos.
   D) $64$ valores distintos.
   -> Respuesta correcta: B) $256$ valores distintos.

2. [Nivel: Intermedio] ¿Cuál es la representación hexadecimal del número binario $1101\,1010_2$?
   A) $\text{CA}_{16}$
   B) $\text{DB}_{16}$
   C) $\text{DA}_{16}$
   D) $\text{E2}_{16}$
   -> Respuesta correcta: C) $\text{DA}_{16}$

3. [Nivel: Básico] ¿Cuántos bits utiliza el estándar ASCII original para codificar cada carácter?
   A) $7$ bits.
   B) $8$ bits.
   C) $16$ bits.
   D) $4$ bits.
   -> Respuesta correcta: A) $7$ bits.

4. [Nivel: Intermedio] ¿Qué característica define principalmente a la codificación de caracteres UTF-8?
   A) Utiliza siempre $2$ bytes fijos para todos los caracteres.
   B) Es incompatible con el estándar ASCII de $7$ bits.
   C) Solo permite representar alfabetos europeos occidentales.
   D) Usa longitud variable de $1$ a $4$ bytes.
   -> Respuesta correcta: D) Usa longitud variable de $1$ a $4$ bytes.

5. [Nivel: Básico] ¿Qué unidad de memoria equivale exactamente a $1024$ bytes según el estándar IEC?
   A) Kilobyte ($\text{kB}$).
   B) Kibibyte ($\text{KiB}$).
   C) Megabyte ($\text{MB}$).
   D) Mebibyte ($\text{MiB}$).
   -> Respuesta correcta: B) Kibibyte ($\text{KiB}$).

6. [Nivel: Intermedio] ¿Cuál es el resultado de aplicar la operación bit a bit XOR entre $1010_2$ y $1100_2$?
   A) $1000_2$
   B) $1110_2$
   C) $0110_2$
   D) $0010_2$
   -> Respuesta correcta: C) $0110_2$

7. [Nivel: Básico] ¿Cuál es la función principal de la memoria RAM en un sistema informático?
   A) Almacenar archivos de forma permanente sin energía eléctrica.
   B) Guardar temporalmente datos e instrucciones en ejecución.
   C) Ejecutar directamente operaciones aritméticas y lógicas.
   D) Gestionar la comunicación física con la tarjeta de red.
   -> Respuesta correcta: B) Guardar temporalmente datos e instrucciones en ejecución.

8. [Nivel: Intermedio] ¿Cómo almacena un sistema Little-Endian un entero de $32$ bits en la memoria principal?
   A) Coloca el byte más significativo en la dirección menor.
   B) Almacena los bits en orden inverso dentro de cada nibble.
   C) Coloca el byte menos significativo en la dirección menor.
   D) Divide el entero en dos palabras independientes de $16$ bits sin orden fijo.
   -> Respuesta correcta: C) Coloca el byte menos significativo en la dirección menor.

9. [Nivel: Básico] ¿Qué componente del sistema operativo gestiona la asignación de tiempo de CPU a los procesos?
   A) El planificador.
   B) El cargador de arranque.
   C) El sistema de archivos.
   D) El controlador de dispositivos.
   -> Respuesta correcta: A) El planificador.

10. [Nivel: Intermedio] ¿Qué situación ocurre cuando dos hilos bloquean recursos mutuos esperando cada uno al otro?
    A) Condición de carrera.
    B) Desbordamiento de pila.
    C) Fragmentación externa.

    -> Respuesta correcta: D) Interbloqueo.

41. [Nivel: Básico] ¿Qué diferencia existe entre autenticación y autorización en seguridad informática?
